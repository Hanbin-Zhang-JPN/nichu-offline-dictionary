`data/stats.json` 是机器可读报告；`data/manifest.json` 记录上游文件和附带快照的 SHA-256。词条包括词语、汉字、专名、罗马字、转引词条和源词形，不能把词条数等同于彼此独立的现代日语词汇量。一个词头可能有不同读音、词性或语源记录，按不同词条保留。

## 导入原则

1. 从完整中文版本原始 dump 中选取所有 `lang_code=ja` 记录，涵盖上游 `日语` 与 `日語` 标题对应的记录，避免只下载其中一个分组。
2. 完全相同的记录按完整 JSON 哈希去重；不同词性／语源／读音记录不合并，避免丢失义项归属。
3. 原始字段整体保存，含 ruby、义项、用例、发音、词形、语源、用法说明及相关词等。仅没有任何非空 `glosses` 的记录不进入查询索引；仍保留在快照。
4. 读音仅来自源明确的假名、源 canonical ruby、发音字段或精确对应词头的 `词头【假名】` 文本。旧条目的未结构化读音被提取，但不猜测未知读音。
5. 罗马字是机械生成的检索辅助字段。规范化统一 NFKC、大小写及片假名→平假名；基础赫本式促音、拗音与长音有宽松别名。不能代替专业转写、分词或日语形态分析。
6. 活用查询索引源 `forms` 及其 `hiragana`、`roman`，不将量词错误视为词条的别名。源词形末尾的上标脚注仅在索引别名中去掉，原文仍保留。
7. 中文释义做简体检索视图；展示可切回原文。日语词头和例句保持原文。OpenCC 两张表的最长匹配转换不是完整地区用语转换。

## 已知限制

- 73,829 个词条没有结构化词性，界面显示“未标注词性”。一些旧源释义把词性、读音和用例混在一段文字中，原文保留，未将模糊内容自动推断为结构字段。
- 例句统计只计 `senses[].examples`；旧释义中的内嵌例句仍可读，但不计入“有例句”筛选。引文和例句按源记录统计，未宣称每条都有中文翻译。
- 发音字段可能只有 IPA、源音调或媒体链接，不能将 28,434 个词条理解为都有音调或音频。没有下载任何音频；朗读依赖已有本地系统日语语音。
- 原始数据可能包含重复文字、旧式标题、过时释义、混合语言相关词或源提取问题。简体视图可能转换释义和语源中嵌入的汉字表达；原文视图和快照可用于核对。
- 未提供未有可靠源支持的 JLPT、使用频率、考试词表或任意句子翻译。中文反查是释义子串匹配，不能理解同义表达。
- 词条 ID 为记录内容 SHA-256 的前 24 位。同一快照可稳定重建；上游内容更新后 ID 可能改变，学习记录不会自动迁移。

## 更新数据

更新需要联网，普通查词不需要。先停止词典服务，并备份学习记录和当前 `data/`；然后查看 [Kaikki 原始数据页](https://kaikki.org/zhwiktionary/rawdata.html)，记录实际 dump／提取日期。

```bash
# 下载上游文件（仅这一行需要联网，约 224 MiB；上游体积可能变化）
curl -fL --retry 3 https://kaikki.org/zhwiktionary/raw-wiktextract-data.jsonl.gz -o /tmp/zhwiktionary.jsonl.gz

# 用数据页所示的真实日期替换下面日期
python3 scripts/import_source.py /tmp/zhwiktionary.jsonl.gz \
  --dump-date 2026-10-01 --extraction-date 2026-10-02

# 以下步骤全部离线
python3 -m nichu.build > data/stats.json
python3 scripts/verify_data.py
python3 -m unittest discover -s tests -v
```

Windows 可使用 `curl.exe` 下载到本地目录，用 `py -3` 运行 Python，并用实际文件路径替换 `/tmp/...`。导入脚本只读取本地文件，若少于 1000 条日语记录会拒绝替换。快照压缩头固定时间戳，标准化 JSON 与内容哈希提供可核对的重建输入。新 manifest 会让下次启动重建索引；统计报告与 README 的计数需要一并更新。

维护者更新 OpenCC 表时也必须更新 `manifest.json` 中的文件校验值，保留许可证和原始文件头。不要在日语词头上使用中文繁简转换。
