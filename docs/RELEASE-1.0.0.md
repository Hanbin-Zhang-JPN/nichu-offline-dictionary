首个可离线使用的日中词典版本。

- 112,182 个不同词头、120,749 个可查询词条、147,559 个义项。
- 12,492 条结构化用例／引文，97,187 个词条有可提取假名读音。
- 支持日语、假名、罗马字、源活用词形和简繁中文反查。
- 提供网页、命令行、本地只读 API、收藏／历史与学习记录备份。
- 中文维基词典源 dump：2026-10-01，Kaikki 提取日期：2026-10-02；词库 CC BY-SA 4.0，应用 MIT。

下载 ZIP 后解压，需要预先安装 Python 3.10+。macOS 可双击 `start.command`，Windows 可双击 `start.bat`；也可在解压目录执行 `python3 -m nichu.server`。ZIP 附带预建 SQLite 索引和完整源快照，首次启动也不需要互联网。

`SHA256SUMS` 提供下载包校验值。“完整”指所选数据快照的日语记录；词条内容深度与字段覆盖不均匀，详见 README 和数据报告。朗读需要已有的本地日语语音；终端服务须保持运行。
