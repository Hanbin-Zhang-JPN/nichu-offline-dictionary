# 架构

## 运行路径

```text
附带 JSONL.GZ 快照 + manifest + OpenCC 表
        │ SHA-256 校验 / 保留原始字段 / 建立搜索别名
        ▼
SQLite entries + aliases + metadata（原子替换生成）
        │ 参数化只读 SQL
        ├── Python CLI → 文本 / JSON
        └── 127.0.0.1 HTTP API → 本地 HTML / CSS / JS
                                     │
                                     └── localStorage 收藏 / 历史 / JSON 备份
```

Python 3.10+ 标准库构成全部运行依赖。网页无需构建，所有静态资源由本机白名单路由返回。第一次启动从本地压缩源生成索引，后续直接读取索引；manifest 发生变化时重建。索引写入临时文件、事务完成并关闭连接后原子替换，构建失败保留旧索引。

## 检索模型

- `entries`：内容哈希 ID、源词头、结构化 POS、显示词性、读音、罗马字、预览、规范化简体释义、用例计数、原始 JSON payload。
- `aliases`：NFKC 和假名标准化后的词头、读音、罗马字及源词形，复合主键 `(key, entry_id)`；B-tree 范围实现前缀查询。
- `metadata`：manifest 与构建统计。

日语精确别名 rank=0，前缀 rank=1，包含 rank=2，中文释义子串 rank=3。同一词条取最低 rank，稳定排序后分页。转引／罗马字／未标注词性词条在相同 rank 中靠后，其后按词头长度、文字和 ID 排序；排序并非词频排名。没有 FTS 扩展依赖，中文反查使用规范化释义的子串扫描；这使一到两个汉字查询也可准确工作。大词库中反查扫描开销高于 B-tree 精确查询。

每次请求新建只读 SQLite 连接并及时关闭，线程不共享连接。查询、筛选和分页均参数化；搜索长度最多 120 字，每页最多 100 条。客户端 debounce 与 AbortController 避免无用查询；序列号避免旧响应覆盖新查询和新详情。

## 离线与数据边界

服务只绑定 `127.0.0.1`，校验 Host 为当前端口的 `localhost` 或 `127.0.0.1`。未开放写入 API、跨域访问或任意文件路径；只返回指定静态资源与词典查询。CSP 禁用外部脚本、外部样式和外部资源请求。源文本经 HTML 转义展示，词条不能执行脚本。

浏览器与回环 HTTP 服务的通信不需要互联网。断开互联网后服务仍可查词，但终端服务必须保持运行。没有 Service Worker 离线网页缓存或 GitHub Pages 部署承诺；静态宿主不能执行此 Python 查询服务。源媒体 URL 仅作为原始字段保留，不自动请求。仅系统本地日语 voice 被用于可选朗读。

学习记录留在浏览器，同一端口／浏览器地址内持久化，不上传至 GitHub 或任何远端。JSON 导入校验版本、ID、字段长度、数量与 2 MiB 文件大小；合并同 ID 收藏与去重历史。导入记录中的释义预览也经过转义；最新详情从本地索引读取。

## 扩展方向

可以通过新的合法数据适配器增加例句覆盖、可靠的考试等级、独立频率资源或本地授权音频；每个资源应独立保留许可与来源。大型词库可加入可选 FTS／N-gram 索引，并继续支持短中文查询。未来更新迁移可按词头＋词性＋读音匹配旧收藏，并向用户展示歧义；当前版本不自动猜测迁移结果。
